Numerical Methods in Computational Geodynamics

Finite element methods (FEM) and spectral element methods (SEM) are the workhorses of computational geodynamics. These techniques discretize the governing partial differential equations — including the wave equation, Stokes flow, and heat equation — into systems of algebraic equations that can be solved on modern computing architectures.

The finite element method partitions the computational domain into a mesh of elements (triangles, quadrilaterals, tetrahedra, or hexahedra). Within each element, the solution is approximated by polynomial basis functions. The weak formulation of the governing PDE ensures that the method handles complex geometries and heterogeneous material properties naturally. Higher-order elements (quadratic, cubic) improve accuracy at the cost of additional degrees of freedom.

Spectral element methods combine the geometric flexibility of finite elements with the exponential convergence of spectral methods. By using high-order Lagrange polynomials on Gauss-Lobatto-Legendre points, SEM achieves spectral accuracy while maintaining element-wise structure. This makes SEM particularly efficient for wave propagation problems, where high accuracy per wavelength is essential. The SPECFEM family of codes, widely used in seismology, employs SEM for global and regional earthquake simulations.

Adaptive mesh refinement (AMR) concentrates computational resources in regions with high solution gradients, such as fault zones or phase boundaries. Octree-based AMR dynamically subdivides hexahedral elements, while h-adaptivity adjusts element sizes and p-adaptivity increases polynomial order locally. Balancing refinement criteria with load distribution across processors is a key challenge for parallel AMR.

Time-stepping schemes must balance accuracy with stability. Explicit methods like Runge-Kutta and leapfrog are simple to implement and parallelize but are subject to the Courant-Friedrichs-Lewy (CFL) condition, which limits the time step based on the smallest element and fastest wave speed. Implicit methods remove this restriction but require solving large linear systems at each step, making them computationally expensive for wave problems.

Preconditioning is essential for efficient iterative solvers. Multigrid methods, both geometric and algebraic (AMG), reduce iteration counts by addressing error components at multiple resolution levels. Domain decomposition preconditioners partition the problem across processors, with Schwarz-type methods exchanging boundary data. For indefinite systems arising from Stokes equations, block preconditioners that exploit the saddle-point structure are necessary.

Matrix-free implementations avoid assembling global stiffness matrices, computing matrix-vector products element-by-element instead. This approach reduces memory requirements from O(N^2) to O(N) and improves cache efficiency on modern architectures. Combined with sum factorization for tensor-product elements, matrix-free SEM can achieve near-peak hardware performance.
