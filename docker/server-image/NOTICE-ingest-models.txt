Bundled knowledge ingest models (ADR-116 amendment, 2026-11-13)
================================================================

This directory holds model weights that Dockerfile.server staged at build
time with `python ingest_models_stage.py stage docling|gliner`, each at a
pinned commit; `ingest_models_stage.py verify` failed the build had any
staged marker recorded another. They are
redistributed unmodified, except that GLiNER's gliner_config.json is
rewritten to load its backbone from the local backbone/ directory. Each
staged directory carries the upstream model card (README.md) and a
.umrs-staged.json marker that records what was staged.

The libraries that load these models are installed from the image lock:
docling (MIT) and gliner (Apache-2.0). The full Apache License 2.0 text,
which covers items 1 and 3, ships in the image at
/usr/local/lib/python3.11/site-packages/gliner-*.dist-info/licenses/LICENSE.
(docling's own dist-info carries no licence file; its licence is MIT per
its package metadata.)
