## Analysis Methodology

**Algorithm:** Incremental frame-difference motion detection with morphological filtering

**Per-video-pair pipeline:**
1. Convert MP4 → PNG frames (via ffmpeg/ffprobe)
2. Compute absolute frame differences (cv2)
3. Binarize (threshold), morphological closure/opening
4. Merge detections within distance threshold (`dt=0.05`) and time threshold (`tt=15s`)
5. Output event TSV with (camera, video_pair, start_time, end_time)

**Aggregation:** All per-pair TSVs merged into `results/motion_events.tsv`
