## Directory Structure

- `data/` — Test data used in experiments
- `Disk_test/` — Scripts for disk performance evaluation
- `Infinia_demo/` — Main directory containing UMRS source code and tests
- `minio_trigger_test/` — Scripts to test MinIO as a standalone service
- `NIM_test/` — Preliminary scripts for testing NVIDIA NIM
- `redsql/` — All RedSQL-related work: documentation and scripts
- `S3_Postgres_PGVector_demo/` — Standalone scripts to test the PGVector extension in PostgreSQL
- `s3_test/` — Standalone tests on S3

## Installing and Running UMRS

1. Navigate to the `Infinia_demo/` directory.
2. Read `doc/HOWTO.md` for an overview and setup instructions.
3. Use `doc/set-up_pgvector.md` for detailed PGVector installation steps.
4. Test the setup by following the instructions in `demo.md`.
